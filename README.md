# No Screenshot Box

No Screenshot Box customizes the GNOME Shell screenshot area selector.

## Compatibility

GNOME Shell 45-50.

## Features

- Starts the area selector without GNOME Screenshot's preselected rectangle.
- Optionally captures the selected area when the drag ends.
- Can mute only the screenshot capture sound.

## Installation

Install the extension archive through the Extensions app or with
`gnome-extensions install`. The extension UUID is
`no-screenshot-box@screenshot`.
